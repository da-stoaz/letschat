CLAUDE-UI.md

If you are working on any user-facing frontend, consider these rules in order to generate an intuitive design and a good user-feeling. 

- When having any toggle switches who have dependent fields, hide these dependent fields or collapse them when the toggle switch option means that the dependent fields are inactive. 

- Never show a status badge that repeats what an adjacent control already says. If a
  button reads "Joining…", a badge next to it reading "Joining…" is noise. Show the
  badge only for states the control itself cannot express (e.g. "In call" when a call
  is running that you are not part of).
